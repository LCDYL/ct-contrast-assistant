# CT 对比剂智能选择系统

一个用于展示增强 CT 碘对比剂选择与参数计算流程的软件测试项目。系统将体型、检查类型、肾功能、心功能、过敏与病史、静脉通路等信息组织为六步表单，按照项目设定的规则生成对比剂品规、注射参数和风险分层，并展示各项输入如何影响计算结果。

项目围绕“信息录入 → 参数计算 → 方案展示”展开，帮助理解增强 CT 检查中对比剂浓度、注射流率、总量与个体条件之间的关系。

## 主要功能

- **六步信息录入**：依次填写基础信息、检查方案、肾功能与代谢、心功能、过敏与病史、静脉通路，支持返回前一步修改。
- **实时指标预览**：根据当前输入显示体质指数、体表面积、估算肾小球滤过率和肌酐清除率等指标。
- **方案生成**：展示对比剂品规与备选品规，以及浓度、体积、注射流率、注射时长、碘总量、碘流率和盐水冲管量。
- **风险分层**：按项目规则展示急性不良反应与过敏、对比剂相关肾损伤、心功能与容量负荷、二甲双胍相关乳酸酸中毒、静脉外渗五项风险，以及相应的评分因素。
- **计算过程说明**：通过决策链路说明体型修正、参数限制、静脉通路条件与最终方案之间的联系。
- **示例与报告导出**：内置示例便于快速体验，结果页支持浏览器打印和保存为 PDF。

## 使用方式

1. 打开网页，点击“看示例”快速查看完整结果，或按六步表单填写信息。
2. 完成录入后点击“生成方案”，查看给药参数、风险分层、关键提示和决策链路。
3. 返回表单调整输入，可比较不同条件下的结果。点击“导出报告”，可在浏览器打印窗口中打印或保存为 PDF。

系统支持冠状动脉 CTA、头颈动脉 CTA、肺动脉 CTA、腹部常规增强、肝脏动态三期等检查类型，也支持低 kV / 低剂量设置和不同静脉通路条件。改变检查类型、体型或通路条件，可以观察参数与结果的对应变化。

## 网页体验

网页计算在浏览器中完成。界面适配桌面与移动设备，录入过程中可查看实时指标，生成结果后可返回修改或重置表单。

如需在本地体验，下载仓库并在 PyCharm 等 IDE 中运行根目录的 `1_本地预览.py`，浏览器会自动打开页面。预览程序仅使用 Python 标准库。

## 软件验证

项目使用 1,243 组合成输入，对 Python 与 JavaScript 两种实现的完整评估结果和实时预览结果进行逐字段比较，共 2,486 项比较全部通过。用例涵盖定向与边界输入、检查类型与通路条件交叉组合，以及固定种子生成的组合输入。

此外，在 Microsoft Edge 中完成了 10 类浏览器验收，覆盖六步录入、表单校验、示例加载、返回修改、重置、打印、移动端显示，以及重复提交、过期结果和计算失败后的恢复。上述结果反映软件计算与页面交互的验证情况。演示示例和算法测试均采用合成数据。
